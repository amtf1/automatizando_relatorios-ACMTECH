# Gerador de Relatórios Técnicos

**Status:** Em desenvolvimento 🚧

## Sobre o projeto

Aplicação web criada para facilitar a elaboração de relatórios técnicos de manutenção industrial.

O projeto surgiu a partir da experiência com a elaboração de relatórios de manutenção, identificando a oportunidade de automatizar a organização de fotografias, descrições e informações técnicas.

## Funcionalidades planejadas

- Cadastro das informações do serviço realizado.
- Upload de fotografias.
- Inclusão de descrições para cada imagem.
- Organização automática do conteúdo em um modelo de relatório.
- Geração e exportação de relatórios em PDF.

## Objetivo

Reduzir o trabalho manual na elaboração de relatórios e desenvolver uma solução prática para documentação técnica.

## Status do desenvolvimento

O projeto está em fase de desenvolvimento. As funcionalidades descritas representam os objetivos planejados e ainda não estão necessariamente implementadas.
